Ember & Ladle — Hearthside Rush: a timed top-down cooking game. Run a 150-second lunch shift: grab ingredients from the crates, chop them on the boards, cook them on the stoves, build each plate on the assembly counter, and serve matching dishes at the golden window before the ticket's patience runs out. Three recipes, combos, burnt food, wrong-dish penalties, and a best score to beat.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys, use stations with Space or E, click a station to walk there, P pauses, R restarts.
